# 13 — Books in-game

Catálogo de **livros legíveis** dentro de Tibia, agrupados por área/coleção. Tibia tem **centenas** de livros — este documento é o **catálogo curado + amostras de texto canônico**. Para textos completos individuais, ver metodologia de fetch ao final.

## Como o catálogo foi construído

Compilado de:
- **"Books of Tibia" archive** by Padex (Nightmare Knights project) — base inicial dos livros clássicos.
- **TibiaWiki Category:Books / Category:Book Texts** (Tier 2 wiki).
- **Tales of Tibia libsearch** — base merge de tibia.fandom.com + tibiawiki.com.br.
- **TibiaWiki BR (PT)** — útil quando inglês bloqueado.

> **Limitação importante:** TibiaWiki Fandom **bloqueia** WebFetch direto (403). Quando precisar do texto completo de um book específico, use uma das estratégias na seção "metodologia" no fim.

## Coleção 1 — Tibian History / Genesis (Knightmare, 2001-2002)

A "Bíblia da cosmologia de Tibia". 7 capítulos, alguns subdivididos em múltiplos livros.

### Capítulo 1: The Awaking of the Gods (Books I-II)

> "Before Fardos and Uman Zathroth existed, there was only the void, which was everywhere and nowhere at once. Whether they had always existed and eventually awoke from the slumber of infinity, nobody knows."

Aborda o despertar de Fardos e Uman Zathroth no Vazio. Uman ainda inclui Zathroth como sua metade sombria — não há separação ainda.

### Capítulo 2: The Great Creation (Books I-II)

Uman e Fardos atraem Tibiasula. Uman inventa **o tempo** pra dar substrato ao trabalho criativo. Zathroth forja a adaga e **mata Tibiasula**. Os deuses prendem o corpo dela à coluna do tempo.

### Capítulo 3: The Birth of the Elements (Books I-IV)

Do corpo dispedaçado de Tibiasula nascem **Tibia (terra), Sula (água), ar, fogo**.

### Capítulo 4: The War over the Creation (Books I-IV)

Uman é atormentado por sua metade sombria; pede a Fardos pra separá-lo de Zathroth. A separação acontece e Zathroth nasce como entidade independente — porém pra sempre ligado a Uman. Guerra começa.

> "Book One begins with Uman being distressed by the actions of his dark side, asking Fardos to help him separate from his bad side."

### Capítulo 5: The First Creatures (Books I-II)

Uman + terra geram **Crunor**. Uman + Sula geram **Bastesh**. Fardos + fogo geram **Fafnar e Suon**. Fardos + ar gera **Nornur**. Zathroth seduz Fafnar; nasce **Brog**.

Brog cria **dragons, trolls, goblins, cyclopes, orcs**.

### Capítulo 6: Tibia's Renewal (Books I-II)

Armistício temporário entre os deuses. Mundo é "renovado" e estabilizado.

### Capítulo 7: The Creation of Humans (Books I-III) + The Vocations + The Soulvortex

Fardos e Uman criam **Banor**, primeiro humano. Da geração de Banor surgem **vocações** (Knights primeiro, depois Paladins, Druids, Sorcerers). Magia é "introduzida" via Druidas inspirados por Crunor.

A **Soulvortex** é o portal divino que permite almas se manifestarem como heróis (= players) em Tibia.

## Como capturar o texto completo

### Opção principal — Scraper automatizado (recomendado)

O projeto tem um scraper em `scripts/scrape-books.ts` que baixa **todos** os books de `Category:Book_Texts` via MediaWiki API. ~1224 books capturados na última run.

```bash
# Dry run (10 books — pra validar parser depois de mudanças):
pnpm scrape:books:dry

# Full scrape (~10-12 min, ~1200 books):
pnpm scrape:books

# Retoma após erro de rede:
pnpm scrape:books:resume

# Gerar SQL seed pra Supabase:
pnpm seed:books        # ON CONFLICT DO NOTHING
pnpm seed:books:upsert # ON CONFLICT UPDATE (use pra refresh)
```

Output:
- `data/books-raw.jsonl` — 1 linha JSON por book parseado.
- `supabase/seed_books.sql` — INSERT batches pra `public.books`.
- `data/books-scrape.log` — log temporal.

Aplicar no DB:
```bash
supabase db push       # roda migrations + seed
# OU manualmente:
psql ... -f supabase/seed_books.sql
```

### Fallbacks (quando scraper não cobre)

Pra books **novos in-game** ainda não transcritos na wiki, ou pra cross-check:

1. **Tales of Tibia libsearch** — `https://talesoftibia.com/libsearch/?t=NOME` (merge de pt-br + en).
2. **TibiaWiki BR** — `https://www.tibiawiki.com.br/wiki/NOME_(Book)` (textos em inglês, espelho parcial).
3. **Wayback Machine** — `https://web.archive.org/web/*/tibia.fandom.com/wiki/NOME_(Book)`.
4. **Nightmare Knights archive** — `nightmareknights.com/historyprojects/books.html` (resumos).
5. **In-game transcription** — gold-standard pra books raros/novos. Submeter via UI moderada do fansite.

### Como o scraper trata os campos

| Campo do book in-game | Mapeamento |
|---|---|
| Título da página da wiki | `title` (UI, sem "(Book)") |
| Capa real do livro in-game | `inGameTitle` (pode ser "Untitled") |
| Template sprite (Book Brown/Black/Grey) | `booktype` |
| Texto principal | `text_md` (markdown limpo) |
| Status do texto | `textStatus`: `ok` / `empty` / `unknown_language` / `image_only` / `missing` |
| Localização in-game | `location_md` |
| Página de retorno (library) | `returnPage` |
| Links relacionados | `relatedPages` |
| Notas wiki | `notes` |
| Versão do client | `implementedVersion` |

### Compliance

- Source: TibiaWiki Fandom (CC-BY-SA).
- Atribuição obrigatória em qualquer publicação derivada — UI mostra "Source: TibiaWiki, CC-BY-SA" no footer de `/books/[slug]`.
- Rate limit do scraper: 4 req/s (250ms entre requests). Política conservadora.
- User-Agent identifica projeto + contato — convenção MediaWiki.

## Implementação no fansite

### `/books`

Página index com:
- Filtro por **coleção** (Genesis, Mainland, Demona, Ankrahmun, etc).
- Filtro por **cidade / library**.
- Search por título.
- Card por livro: título, location, blurb 1 frase, "ler texto completo →".

### `/books/[slug]`

- Texto completo do livro (markdown).
- Sidebar: outras obras da mesma coleção.
- Tags: tema (cosmology, races, history, satire).
- Link "ver in-game em [location]" — coordenada se conhecida.
- Tag de canonicidade (Tier 1/2/3/4).

### Schema sugerido

```sql
books (
  id           uuid pk,
  slug         text unique,
  title        text not null,
  collection   text,           -- 'genesis', 'mainland', 'demona', etc
  location_md  text,           -- "Isle of the Kings Library"
  city         text,           -- 'thais', 'edron', 'ankrahmun', null se random
  series       text,           -- 'War over the Creation', null se standalone
  series_part  int,            -- 1, 2, 3...
  full_text_md text,           -- markdown do texto completo (quando capturado)
  summary_md   text,           -- summary curto (sempre presente)
  source_tier  int,            -- 1, 2, 3, 4 (canonicidade)
  source_url   text,           -- fonte canônica (TibiaWiki etc)
  wiki_url     text,
  created_at   timestamptz default now(),
  updated_at   timestamptz default now()
);

create index on books (collection);
create index on books (city);
create index on books (series);
```

### Seed inicial sugerido

Começar com **Tier 1 / Genesis books** (importância máxima pra lore page):
- 7 chapters de Tibian History.
- The Holy Tible.
- Ancient Races.
- The Cities of the Continent.

Total: ~30 books canon prioritários, full text incluído.

Resto: catálogo (slug + título + location + summary), full_text vazio até captura manual ou request da comunidade ("alguém me ajude a transcrever").

### Crowdsourcing de captura

Banner no `/books/[slug]` quando `full_text_md IS NULL`:
> "Texto completo deste livro ainda não foi capturado. Quer ajudar? Cole o texto in-game aqui." → submission form moderado.

## Guardrails

1. **Texto dos books é propriedade da CipSoft**. Fansite cita sob fair use educacional + atribuição clara.
2. **Não vender/monetizar** acesso a texts (compliance).
3. **Não modificar** texto canon. Sempre transcrever original.
4. **Tier 3/4** marcado com banner ("interpretação comunitária, não canon").
5. **Citar fonte** sempre (TibiaWiki link, Nightmare Knights archive, etc).
6. **Crowdsourced texts** → moderation antes de publicar (anti-vandalism).
